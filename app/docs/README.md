# Documentation

## Tracked docs

Workspace-facing guides live at the repository root (for example `README.md`, `DEVELOPMENT.md`) and under paths that stay in version control.

## Local-only notes (`docs/project/`)

The directory `docs/project/` is **gitignored**. Use it for private or exploratory material (draft bug reports, meeting notes, scratch OpenAPI diffs) that you do not want in shared history.

If you later decide to publish something from there, move or copy the file into a tracked location and edit it for a general audience before committing.
